# Code of Conduct

Sourcebound is a small open-source project and we want it to be a welcoming one.

## Expected behaviour

- Be respectful and considerate, including when you disagree.
- Assume good intent, and ask before assuming.
- Give and accept constructive feedback about code, not about people.
- Help newcomers; everyone started somewhere.

## Unacceptable behaviour

- Harassment, insults or discriminatory language of any kind.
- Personal attacks, trolling or deliberately derailing discussions.
- Publishing others' private information without permission.
- Sexualised language or imagery.

## Enforcement

Maintainers may remove comments, commits, issues and other contributions that break this code, and may block people who repeatedly or seriously do so.

Report problems privately to the maintainer through a [private security advisory](https://github.com/pvc2000-creator/sourcebound/security/advisories/new) (it reaches the maintainer privately even for non-security matters) or by contacting the maintainer through their GitHub profile. Reports are handled confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
